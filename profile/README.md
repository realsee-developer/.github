## Featured projects

### [Argus](https://github.com/realsee-developer/Argus)

Metric panoramic 3D reconstruction for indoor scenes. Accepted to ECCV 2026.

**[View the Argus research page →](https://argus-paper.realsee.ai/?utm_source=github&utm_medium=referral&utm_campaign=realsee_developer_org&utm_content=argus_research)**

### [RealSee3D](https://github.com/realsee-developer/RealSee3D)

A large-scale, multi-view RGB-D dataset with 10,000 real-world and procedurally generated indoor scenes.

**[Explore the dataset →](https://dataset.realsee.ai/?utm_source=github&utm_medium=referral&utm_campaign=realsee_developer_org&utm_content=realsee3d_dataset)**

### [skills](https://github.com/realsee-developer/skills)

Agent and CLI workflows for Realsee Argus, a world-leading 3D vision foundation model.

**[Install Realsee Skills →](https://github.com/realsee-developer/skills#install)**

### [dnalogel](https://github.com/realsee-developer/dnalogel)

Spatial UI layers for tags, rulers, mini maps, camera flows, and other interactions on top of a Realsee scene.

**[Browse dnalogel plugins →](https://open-platform.realsee.com/developer/docs/dnalogel/intro/?utm_source=github&utm_medium=referral&utm_campaign=realsee_developer_org&utm_content=dnalogel_docs)**
